# Магнитка бот 1 — Telegram monitor

MVP Telegram-бота для автоматического мониторинга дневного турнира Magnitka Open и сигналов **M3-TB4.5**, **A+ v4** и **IT-L2 v5**.

## Что делает бот

- За **60 минут до первой игры** начинает активный мониторинг дня.
- Загружает расписание и страницы матчей `mg-open.org`.
- **M3:** за 10 минут до матча №3 присылает готовый прематч-сигнал `ТБ4,5` от **1.50**.
- **A+ v4:** перед 2-м периодом, если предварительные условия соблюдены, присылает **🟡 ГОТОВИМСЯ**. Затем:
  - при 0:0 примерно за 30 сек до 4:50 — предупреждение;
  - при 0:0 на 4:50 — **🚨 СТАВКА СЕЙЧАС**, `ТБ0,5 2П` от **1.40**;
  - если гол случился раньше — **⚪ ОТМЕНА**.
- **IT-L2 v5:** перед 2-м периодом присылает **🟡 ГОТОВИМСЯ** только если проходят фильтры по сопернику/счёту 1П. Затем:
  - если Лисы не забили к 0:30 — предупреждение;
  - если Лисы не забили к 1:00 — **🚨 СТАВКА СЕЙЧАС**, `ИТБ0,5 Лис 2П` от **1.60**;
  - если Лисы забили раньше — **⚪ ОТМЕНА**;
  - гол соперника до 1:00 **не отменяет** IT-L2.
- Считает `RISK / CORE / HIGH / ULTRA`.
- Использует `GK BOOST`, если prior-only P2 concede proxy заявленной вратарской пары/пар ≥ **2.6**.
- Хранит уведомления и историю в SQLite, поэтому не спамит одинаковыми сигналами после перезапуска.
- После завершения всех шести игр автоматически добавляет дневные показатели заявленных вратарей в rolling history.

## Текущие правила стратегий

### M3-TB4.5

- Только матч №3.
- Рынок: ТБ4.5 за весь матч, минимум **1.50**.
- Базовый M3 = `CORE`.
- Если в №3 играют Ледовые Спартанцы или Стальные Топоры = `HIGH`.
- `GK BOOST` повышает уровень на один: CORE→HIGH, HIGH→ULTRA.
- Первые две игры ≥10 — только TEST-контекст, баллов не даёт.

### A+ v4

- Только матчи №3, №5, №6; №4 — SKIP.
- Если первые две игры >10 и в текущем матче есть Ледовые Спартанцы — SKIP.
- Во 2П ждём 0:0 до ~4:50.
- Если 0:0 сохранился: ТБ0.5 2П от **1.40**.
- №3 = HIGH, №5 = CORE, №6 = RISK; `GK BOOST` +1 уровень.

### IT-L2 v5

- Только матчи Хитрых Лис.
- Во 2П ждём до 1:00; Лисы должны ещё не забить.
- vs Свирепые Ежи — HIGH при любом счёте 1П.
- vs Стальные Топоры — HIGH только если Лисы ведут после 1П.
- vs Ледовые Спартанцы — RISK, если после 1П не ничья и это не матч №2.
- vs Меткие Стрелки — SKIP.
- `GK BOOST` считается по заявленной паре соперника и повышает уровень на один.

## Важная техническая оговорка про точку 1:00 / 4:50

Страница матча должна дать боту признак текущего периода и, в идеале, live-таймер. Парсер пытается найти оба. Если сайт показывает период, но не отдаёт таймер в HTML, бот запускает локальный секундомер **с первого обнаруженного обновления «2-й период»**. При `LIVE_POLL_SECONDS=5` систематическая задержка обычно ограничивается интервалом polling, но перед боевым использованием нужно один раз проверить живую страницу во время матча командой `scripts/inspect_page.py`.

Если сайт вообще не отдаёт фазу матча в HTML, бот **не должен выдумывать точку входа по расписанию** — сначала адаптируем парсер к фактическому live-маркеру/API сайта.

## Установка

### 1. Создать Telegram-бота

1. В Telegram открыть **@BotFather**.
2. `/newbot`.
3. Получить токен.
4. Скопировать `.env.example` в `.env` и вставить токен.

```bash
cp .env.example .env
nano .env
```

### 2. Запуск через Docker

```bash
docker compose up -d --build
```

Логи:

```bash
docker compose logs -f
```

### 3. Или локально Python 3.12+

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -m app.main
```

После запуска открой своего бота в Telegram и нажми **Start** / отправь `/start`.

## Команды Telegram

- `/start` — подписаться.
- `/status` — состояние монитора.
- `/today` — расписание дня.
- `/mute` — отключить пуши.
- `/unmute` — включить пуши.

## Проверка live-парсера

Во время реального матча:

```bash
python scripts/inspect_page.py https://mg-open.org/game/1/5122.html
```

Нужно увидеть примерно:

```text
live_period: 2
live_elapsed_seconds: 75
```

или хотя бы `live_period: 2`. Во втором случае бот использует локальный секундомер с момента первого обнаружения второго периода.

## Данные GK proxy

`data/goalie_seed_august_2026.json` — стартовая история из августовской исследовательской базы. Значение — **proxy командной пропускаемости в дни, когда фамилия была заявлена в паре**, а не персональная статистика фактически игравшего стартера.

Для нового вратаря применяется сглаживание: 3 псевдо-дня со средним 2.7 пропущенных во 2П на командо-день.

## Часовой пояс

В `.env.example` по умолчанию стоит:

```text
TOURNAMENT_TZ=Asia/Yekaterinburg
```

Это UTC+5. Внутренняя логика уведомлений ориентируется на время турнира/сайта. Если выяснится, что сайт публикует время в другом часовом поясе, достаточно поменять переменную — код стратегий не меняется.

## Что ещё НЕ автоматизировано

- Получение live-коэффициентов букмекера. Пока сообщение говорит **«брать от 1.40 / 1.50 / 1.60»**, коэффициент проверяется вручную.
- Автоматическая ставка в БК — отсутствует.
- Фамилии полевых игроков не влияют на баллы, пока не подтверждены OOS.

## Bothost.ru

Для Bothost-ready версии файл SQLite хранится в `/app/data/magnitka_bot.sqlite3`, а стартовая история вратарей вынесена в `seed/goalie_seed_august_2026.json`, чтобы постоянный каталог `/app/data` не перекрывал seed-файл при деплое.

При создании бота на Bothost включите **Использовать собственный Dockerfile**. Токен передаётся через поле **Bot Token**/переменную окружения, а не хранится в Git.
